**Course - 1. Intro to Front-End Development** 

Sections: 

Many of the activities you do everyday can be entirely performed online. For example, shopping, reserving hotels, chatting with friends and colleagues, etc. 

All this is possible with the combination of internet infrastructure and technologies, and skilled professionals who build the apps (phone apps or web apps) you use. 

What are front end, back end, and full stack development? 

Web developer roles are usually split into front end, back end, and full stack roles. 

A front end developer works with all the parts of a website or web app that the users interact with.

For example, consider style, colors, buttons, menus, user interactions like clicking and swiping, etc. 

A front end developer focuses on three leading technologies, HTML, CSS, and Javascript. 

**Eg**: Suppose you are a front end developer assigned with the task of adding a newsletter sign up option to the home page of a website.    

In this case you use HTML to build the display elements, such as the input area for the user to enter the email address, and the button to click to send it.  

You can then use CSS to position, color, style these elements on the page. 

Finally you can use Javascript to process the activity when the user clicks the button. This could be something like checking the email id is valid, and then sending the email id to the website for storage under newsletter members. 

Javascript is the powerhouse of front end technology. 

A back end developer works with all the parts of a website or web app that the end users don't see. 

Back end developers are responsible for creating and maintaining functionality when users request information or when the website needs to communicate to another part of the web architecture. 

**Eg**: Consider performing an account login, or completing an online purchase using aa credit card. A back end developer facilitates the interaction of the website and the content stored in a database. 

Back end knowledge consists of knowledge of back end programming language, database management systems, APIs, and web servers. 

A full stack developer is someone comfortable working with both front end and back end technologies. 

How does the internet work? 

Two devices connect and communicate via a wired or wireless connection, forming something called a network. 

You can connect multiple devices to this network, but this becomes very complicated very quickly: each device needs to connect to every other device to communicate effectively.
